## 1. 構成

```
todoappApp.swift          App。ModelContainer と ThemeManager を生成
ContentView.swift         ルート画面。左にグループ列、右にタブとタスク一覧、＋ボタン、サイドパネル
Models/
  TodoGroup.swift         グループ（名前・絵文字・色 hex・並び順）→ tasks / subgroups（cascade）
  SubGroup.swift          サブグループ（開閉状態つき）
  TodoTask.swift          タスク（メモと表示モード、期限、繰り返し、完了日）＋ RepeatInterval
ViewModels/
  TaskViewModel.swift     完了切り替え（繰り返しなら次のタスクを作る）・追加・更新・削除
  GroupViewModel.swift    グループとサブグループの CRUD、並び替え
Utilities/
  ThemeManager.swift      UserDefaults に保存する設定 7 項目（ObservableObject）
  ColorExtensions.swift   hex ⇄ Color、AppTheme（パステル 8 色）
  DateExtensions.swift    今日／今週／今月／過去 の判定
Views/
  GroupListView           左端 60pt のグループアイコン列と「≡」ボタン
  TabBarView              日／週／月／全て／履歴 の自作タブ（件数つき）
  TaskListView            未完了、サブグループ、完了済み（日付ごと）の List
  GroupManagementView     左から出る自作のサイドパネル（グループの並び替え・編集・削除・追加）
  GroupEditSheet          グループ作成・編集シート
  TaskEditSheet           タスク追加・詳細シート
  SettingsView            設定シート
  TaskFilter              タブの種類
Components/
  TaskRowView / AnimatedCheckboxButton / EmojiSplashView / GroupIconView / SubGroupHeaderView
```

### 画面の一覧と遷移

| # | 画面 | 開き方 | 種類 |
|---|------|--------|------|
| A | メイン（グループ列＋タブ＋一覧） | 起動時 | NavigationStack |
| B | タスク追加 | ＋ボタン | sheet |
| C | タスク詳細・編集 | タスク行をタップ | sheet |
| D | 設定 | 右上の歯車 | sheet |
| E | グループ管理 | 左下の「≡」 | 自作のオーバーレイパネル |
| F | グループ作成・編集 | E の「新規グループ」「編集」 | sheet（E の上） |
| — | 削除の確認 | スワイプ削除、各「削除」 | confirmationDialog |

### 機能一覧（作り直しても残すもの）

- グループ: 作成、編集（名前・絵文字 12 種・自由な色）、削除、ドラッグで並び替え、未完了件数バッジ、長押しで名前を表示
- タスク: 追加、編集、削除（スワイプまたは詳細から）、完了の切り替え
- タスクの項目: タイトル、メモ（表示なし／1行／全文）、期限（任意）、繰り返し（なし／毎日／3日／1週／2週／1ヶ月）
- 繰り返し: 完了すると、完了日を基準に次のタスクを自動で作る
- タブ: 日（今日が期限）／週／月／全て（期限なしか期限切れ）／履歴（8 日以上前に完了）
- 完了済み: 日付ごと（今日・昨日・n日前・1ヶ月前…）に分けて表示し、開閉できる
- サブグループ: 開閉できる見出し（※作る UI はない。§3 を参照）
- 設定: テーマ 8 色、＋ボタンの位置（左下／右下）、完了済みをはじめから開くか、完了アニメーション、絵文字エフェクト、完了後のフェードアウト、未完了の見出しを出すか
- 初回起動時に「🏠 ホーム」グループを作る

## 4. UI の弱点（HIG を基準に）

### 4.1 メイン画面（A）

| 重要度 | 弱点 | HIG の観点 |
|---|---|---|
| 🔴 | **＋ボタンの白いアイコンが、淡いラベンダーの背景（#E8E2F5）の上にあり、ほとんど見えない。** コントラスト比は約 1.2:1（目安は 3:1 以上）。ダークモードでは淡色の円だけが浮いて見える | 読みやすさ・コントラスト |
| 🔴 | **今どのグループを見ているのかが分からない。** ナビゲーションバーにタイトルがなく、グループ列は絵文字だけ。名前は長押ししないと出ない | 分かりやすさ・現在地の明示 |
| 🔴 | **タスクがないときに何も表示されない。** 空の状態の説明も、次に何をすればいいかの案内もない（ContentUnavailableView はグループ未選択のときしか出ない） | 空の状態 |
| 🟠 | 上部に約 100pt の何もない帯があり、歯車アイコンだけが置かれている。グループ列も同じ高さだけ下にずれていて、場所がもったいない | レイアウト・内容を優先する |
| 🟠 | 自作の「フォルダのつまみ」型タブ。件数を表示しない「履歴」だけ文字の高さがずれている。iOS の標準的な見た目（セグメント、またはスクロールするチップ）と違う | 標準部品との一貫性 |
| 🟠 | 未完了件数のバッジが **0 件でも赤で常に表示**される。赤は「対応が必要」という意味になるので、誤解を招く | 色の意味 |
| 🟠 | 左下の「≡」アイコンが何をするのか分かりにくい（グループ管理を開く） | アイコンの意味 |
| 🟠 | グループ列の色は「選ばれていないと透明度 30%」という違いだけ。選択中かどうかが分かりにくい | 状態の見え方 |
| 🟠 | **ダークモードで、選択中のグループの円と＋ボタンが淡い色のまま強く光って見え、画面の中で一番目立ってしまう**（08） | ダークモードへの対応 |
| 🟠 | 「全て」タブで、表示するタスクがないサブグループでも見出しと区切り線だけが残る。件数は「(2)」と出ている（06） | 一貫性 |
| 🟠 | 選択中のタブだけ白い「つまみ」の形になる。「履歴」を選ぶと、そのつまみの高さが他のタブより低くなる（07） | 一貫性 |
| 🟢 | バッジの数（ホーム＝8）は「すべての未完了」の数で、今見ているタブの件数（日＝4）と合わない | 分かりやすさ |

### 4.2 タスク行（TaskRowView）

| 重要度 | 弱点 |
|---|---|
| 🔴 | チェックボックスのタップ範囲が 20pt しかない（HIG の最小は 44×44pt） |
| 🟠 | 行をタップして反応するのはテキスト部分だけ。余白をタップしても詳細が開かない |
| 🟠 | 期限は `2026/11/12` のような数字の日付だけ。「今日」「明日」のような表示がなく、**期限切れでも見た目が変わらない** |
| 🟠 | 枠線、背景、角丸 8 の組み合わせを List の中で使っていて、iOS 26 の見た目（inset grouped／カード）とも違う、中途半端な見た目 |
| 🟢 | 完了した行が「グレーの背景＋opacity 0.6＋取り消し線」と、薄くする処理が 3 つ重なっている |
| 🟢 | 繰り返しタスクであることが行を見ても分からない（アイコンがない） |

### 4.3 シート・パネル（B〜F）

スクショで新たに確認できた点:

- **B/C:** 期限の日付が「Nov 12, 2026」と英語で表示される。画面の他の部分は日本語なので混ざっている（09）。一覧の日付は「2026/11/12」なので、表記もそろっていない。
- **D:** テーマ名が英語（Lavender など）で、ほかの項目は日本語。Peach と Coral はほとんど同じ色に見える。チェックマークが既定の青で、選んだテーマ色が使われていない（10）。
- **E:**
  - パネルの上に約 100pt の空白がある。
  - 見出しの帯だけに影が付いて浮いて見える。
  - パネルの下端が画面の下まで届かず、後ろのグループ列が見えている。
  - 後ろの画面が暗くならないので、どこをタップすると閉じるのか分からない（12）。
  - 並び替え用のハンドル「≡」が、メイン画面左下の「≡」（＝グループ管理を開く）と同じ形で、意味が二重になっている。
- **F:**
  - 色は ColorPicker の小さな丸 1 つだけで、今どの色なのかが分かりにくい。
  - 下半分が空いている。
  - 保存後にどう見えるかのプレビューがない（13）。
- **VoiceOver:** 読み上げのラベルは、メイン左下の「≡」が「Drag」、＋が「Add」、歯車が「gearshape」になっている（snapshot_ui で確認）。

コードから判断したこと:

| 画面 | 弱点 |
|---|---|
| B/C タスク | タイトル欄に自動でフォーカスが当たらない。メモ欄にプレースホルダーがない。「メモ表示」は分かりにくい言葉。追加と詳細が同じフォームで、詳細では情報の重要度に差がない。シートの高さ（detents）が指定されていない |
| D 設定 | テーマの行が `onTapGesture` で作られていて、Button ではない（VoiceOver でボタンとして読まれない）。閉じるボタン ✕ が confirmationAction の位置にある（右上の ✕ なら `.cancellationAction`、または「完了」の文言が普通）。設定項目の名前が技術用語（Sticky Header） |
| E グループ管理 | 自作のスライドパネル。背景が暗くならない（透明度 0.001 の当たり判定だけ）、スワイプで閉じられない、VoiceOver の焦点がパネルの中に限られない。常に編集モードで、各行に「編集」「削除」ボタンが並んでいて詰まって見える |
| F グループ編集 | 自由に選べる ColorPicker なので、パステルのテーマと合わない色も選べる（さらに §3 の黒になるバグ）。選択中の絵文字の強調が既定の青（accentColor）で、アプリの色と合っていない。絵文字が `onTapGesture` で作られていてボタンとして扱われない |

### 4.4 全体

| 重要度 | 弱点 |
|---|---|
| 🔴 | **アクセシビリティの指定が 0 件。** チェックボックスは「circle」と読み上げられ、グループのアイコンは絵文字しか読まれない。バッジや開閉の状態も伝わらない |
| 🟠 | 文字の大きさを `.system(size: 13/10/11/20/24)` で固定している箇所が多く、Dynamic Type（ユーザーが設定した文字の大きさ）に合わせて変わらない |
| 🟠 | 「視差効果を減らす」の設定を見ていない。絵文字が飛び散る演出がいつも動く |
| 🟠 | 完了したときに触覚フィードバックがない（`sensoryFeedback` 未使用） |
| 🟠 | デザインのルールがない。余白（4/6/8/12/16）、角丸（6/8/10）、影（radius 2/4/8）がファイルごとにばらばら |
| 🟢 | iOS 26 の Liquid Glass は、システムのツールバーボタン（歯車）にだけ自動で付いていて、自作の部品（＋ボタン、タブ、パネル）とは見た目が合っていない |

## 5. 作り直しで特に効果が大きいところ（優先度順）

1. **今いるグループを分かりやすく、ナビゲーションを整理する**（タイトル、グループの切り替え方、管理画面の出し方）
2. **タスク行を作り直す**（44pt のタップ範囲、期限の「今日」などの表示と期限切れの色、繰り返しの印、完了した行の表示）
3. **色・文字・余白のルール**（DesignSystem.swift）。コントラストとダークモードもここで解決する
4. **空の状態**と、＋ボタン（追加のしかた）の見直し
5. **アクセシビリティ**（ラベル、Dynamic Type、視差効果を減らす、触覚フィードバック）

> 機能のバグ（サブグループを作る UI がない、色の hex 変換、フェードアウト設定、Sticky Header の名前）を直すかどうか、いつ直すかは、方針として決めてもらう必要があります。「機能は今のまま」の範囲を超える可能性があるためです。
